## Cursor-Specific Instructions

When using Cursor to create retro reports:

- Read all files in `rnd/agent_summaries/` first when that directory exists.
- Use Cmd+K to query PR discussions and review threads.
- Keep `rnd/templates/retro.md` open while structuring the report.
- Search for relevant agent, template, and instruction files with Cmd+P.
- Use Composer to map review feedback to process artifacts.
- Use Apply to write the retro directly to `rnd/retros/`.
